# STOCK-ALGO

An algorithmic trading and market strategy backtesting platform built with Python. Evaluates stock data, generates buy/sell signals, and measures strategy performance metrics.

## Features
- **Technical Indicators:** Computes moving averages (SMA/EMA), RSI, MACD, and Bollinger Bands.
- **Backtesting Framework:** Tests custom trading strategies against historical market data.
- **Performance Analysis:** Calculates Sharpe ratio, maximum drawdown, and cumulative return.

## Tech Stack
- **Language:** Python 3.x
- **Data & Analysis:** Pandas, NumPy, YFinance / Alpha Vantage API
- **Visualization:** Matplotlib, Plotly
